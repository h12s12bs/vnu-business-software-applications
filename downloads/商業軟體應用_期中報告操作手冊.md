## 第一部分：Google Antigravity App (v2.28.2) 安裝與環境配置指引

為了讓每位同學的企劃構想與個人履歷能夠快速落地並轉化為具體的數位互動原型，本課程全面導入現代化 Google Antigravity 應用程式。請依照以下步驟下載安裝與驗證：

### 1.1 下載與安裝 Google Antigravity 桌面版應用程式
* **官方下載入口**：[https://antigravity.google/download](https://antigravity.google/download)
* **官方更新日誌專頁 (v2.28.2)**：[https://antigravity.google/docs/changelog?tab=hub](https://antigravity.google/docs/changelog?tab=hub)
* **Google Antigravity 官方首頁**：[https://antigravity.google](https://antigravity.google)
* **操作步驟指引**：
  1. 點擊上方官方連結進入 Google Antigravity 官方下載專頁，確認版本為最新穩定版本 v2.28.2。
  2. 依據個人電腦作業系統（Windows / macOS）下載對應安裝套件（`.exe` 或 `.dmg`）。
  3. 執行安裝程式，依照畫面指示完成安裝與初始化設定。
  4. 啟動 Google Antigravity App，使用個人的 Google 帳號登入完成驗證。

### 1.2 登入 GitHub 帳號並建立個人專案儲存庫（開 Repo）
GitHub 是全球專業軟體與企劃專案的託管平臺，亦是展示個人商務履歷與數位成果的最佳舞臺。
* **GitHub 官方登入入口**：[https://github.com/login](https://github.com/login)（支援直接用 Google 帳號連動登入）
* **操作步驟指引**：
  1. 前往 GitHub 官方登入頁面完成登入或以 Email 註冊。
  2. 登入後點擊右上角「**+**」，選擇「**New repository**」（新增儲存庫，即建立專案 Repo）。
  3. **專案命名規範**：建議以履歷或專案英文命名（如 `resume-portfolio` 或 `business-profile`）。
  4. **權限設定**：請務必勾選「**Public**」（公開），並勾選「**Add a README file**」。
  5. 點擊綠色按鈕「**Create repository**」完成專案儲存庫建立。

## 第二部分：行銷企劃與商務分析 SOP 五大階段（期中評量邊界解讀）

本課程嚴謹依循行銷學理經典教材（凌政文 教授著《行銷企劃》圖 1-9）之五階段標準流程。授課教師特別將原圖重新繪製為現代數位流程圖，並精準標記【期中報告】與【期末報告】之學習進度邊界：

* **階段 1：啟動與分析（📌 期中評量範疇）**
  * 核心步驟：接收任務／發現痛點 ➔ 外部總體趨勢 (PESTC) ➔ 內部資源條件盤點。
  * 實質產出：SWOT 綜合分析矩陣（因果推論四象限四部曲）。
* **階段 2：目標與定位（📌 期中評量範疇）**
  * 核心步驟：界定商業目標 (SMART) ➔ 市場區隔 (S) ➔ 目標客群 (T) ➔ 價值定位 (P)。
  * 實質產出：確立品牌與產品/個人價值主張。
* **階段 3：方案發想與設計（📌 期中終點里程碑）**
  * 核心步驟：設計行銷組合方案 (4P：產品、價格、通路、推廣)。
  * 🏆 **實質產出：個人商務履歷 ＋ 線上 MVP 原型網頁驗證（GitHub Pages）。**
* **階段 4：執行與控制（🏆 期末實踐範疇）**
  * 核心步驟：盤點所需資源與供應鏈 ➔ 編製甘特圖時程表 ➔ 建立量化績效考核標準。
* **階段 5：企劃書撰寫（🏆 期末實踐範疇）**
  * 核心步驟：文字潤飾與視覺排版 ➔ 正式專案企劃書 ➔ 成果公開展示。

> 💡 **【授課教師指引：期中評量邊界說明】**  
> 期中報告的核心目的在於驗證「個人專業經歷、市場商業思維與數位實作能力的邏輯合理性」。因此，期中進度要求至【**階段 3 之產出：個人商務履歷 ＋ 初步企劃草案/數據分析展示**】即可！同學們無須過早煩惱龐大的預算編列或複雜的甘特圖時程，請專注將個人優勢與企管分析學理做紮實，並發布出清晰的線上 GitHub Pages 網站！

## 第三部分：七大核心商務 Prompt 指引與示範案例（學生可直接複製）

以下示範案例採《樂肉選品 (LeRou Pet Goods)》寵物經濟專案，同學可依照個人選定之主題（服飾美妝、精品代購、二手車商務、文創餐飲、個人求職履歷等）彈性替換名稱！

### 步驟 1：【發掘痛點與創業動機 Prompt】
```markdown
【角色設定】：微型創業者 兼 商業分析師
【任務目標】：我想以《樂肉選品》為題，主打常溫原肉烘乾零食與毛孩脆片。請幫我從『市售零食添加物』、『鮮食冷鏈運費門檻』與『美學生活體驗』三方面，提煉出 3 個具體痛點與切入緣起。
```
* **AI 真實輸出精華**：
  1. 市售零食過度添加與成分不透明（信任危機）。
  2. 鮮食冷鏈運費高昂（超取常溫僅需 60 元，降低試吃門檻）。
  3. 寵物日常點心欠缺美學儀式感（主打卡滋脆片體驗）。

---

### 步驟 2：【外部總體環境 PESTC 深度分析 Prompt】
```markdown
【角色設定】：商務決策特助
【任務目標】：請針對《樂肉選品》的常溫原肉烘乾零食（厚切雞肉乾、毛孩地瓜肉片），運用政治法律(P)、經濟(E)、社會文化(S)、科技(T)、綠色環保(C)五大構面進行 PESTC 總體環境分析，並說明對本企劃之啟發。
```
* **AI 真實輸出精華**：
  * **P**：農業部食品法規抽驗嚴格，100% 無添加成分透明化。
  * **E**：抗跌小確幸經濟，60 元超取大幅提高首購下單率。
  * **S**：少子化與毛孩擬人化普及，人寵同享下午茶需求大增。
  * **T**：專業低溫慢烘設備普及，個人小批量現烘品質優異。
  * **C**：在地優質產銷溯源肉品與地瓜，落實減碳綠色商務。

---

### 步驟 3：【內部資源盤點與假想敵防護 Prompt】
```markdown
【角色設定】：策略營運顧問
【任務目標】：我身為微型創業者，啟動資金僅 3~5 萬、一人作業、無實體店面。請盤點我的內部優劣勢，並選定大型量販賣場的進口拼裝副產物肉乾為主要假想敵，規劃我的定位防護策略。
```
* **AI 真實輸出精華**：
  * **內部盤點**：優勢在於靈活敏捷與 AI 輔助；劣勢在於初期產能受限。
  * **定位防護**：不進行價格戰，以「100% 看得見的原切纖維」與「小批量新鮮出爐」構建護城河。

---

### 步驟 4：【SWOT 因果推論四象限四部曲綜合矩陣 Prompt】
```markdown
【角色設定】：高級策略規劃師
【任務目標】：請將上述《樂肉選品》的內外部條件交叉，嚴格按照 SO（積極開拓）、WO（借力補強）、ST（防禦轉化）、WT（避險聚焦）的四象限四部曲因果推論邏輯，產出策略矩陣。
```
* **AI 真實輸出精華**：
  * **SO (積極開拓)**：發揮原肉厚切與常溫超取的成本優勢，結合社群視覺內容擴展客群。
  * **WO (借力補強)**：以常溫超商取貨搭配「每週限量預購」，將產能有限轉化為新鮮稀缺優勢。
  * **ST (防禦轉化)**：主動公開檢驗報告與在地農民來源，化市場競爭威脅為品質防線。
  * **WT (避險聚焦)**：專注雙明星單品，不囤積非必要設備，確保週轉資金健康。

---

### 步驟 5：【SMART 企劃目標與三超前瞻思維 Prompt】
```markdown
【角色設定】：專案經理 (PMP)
【任務目標】：請為《樂肉選品》期中 MVP 設定 30 天內可量化驗證的 SMART 目標，並融入『超前意識、超越常規、超越期望』的三超思維。
```
* **AI 真實輸出精華**：
  * **SMART**：30 天內發布 GitHub Pages 網頁，達成 200 次瀏覽並收集 30 份預購意向。
  * **三超思維**：超前意識（低風險切入）、超越常規（洋芋片般酥脆工藝）、超越期望（隨包附贈每日熱量換算卡）。

---

### 步驟 6：【STP 市場定位與 4P 行銷組合 Prompt】
```markdown
【角色設定】：行銷總監 (CMO)
【任務目標】：請為我擬定 STP（市場區隔、目標客群、品牌定位），並規劃 4P 方案（包含厚切肉乾、脆脆洋芋片、透氣背心三款商品規格、常溫超取運費 60 元策略、以及 #毛孩卡滋挑戰 社群推廣）。
```
* **AI 真實輸出精華**：
  * **STP**：鎖定 20~35 歲都會男女飼主，主張「樂肉選品，讓毛孩每一口都快樂」。
  * **4P**：產品 A/B/C 三合一、體驗組合價 399 元、GitHub Pages 型錄超商取貨通路、社群卡滋挑戰推廣。

---

### 步驟 7：【一鍵生成線上 MVP 網頁程式碼 Prompt】
```markdown
【角色設定】：全端工程師 兼 視覺設計師
【任務目標】：請幫我閱讀 https://docs.google.com/document/d/1J2bpLVkO6gyPXMCzVMXWa2nA-Bx9kOVU9FHH9PadNc4/edit 此檔案，
並根據此檔案，幫我生成《樂肉選品》XXX主題 (請各位同學自行更改主題，不能以寵物食品，這是範例，可以用賣衣服、代購精品包、賣二手車等等主題不限) 初步企劃草案，
生成為一個單一檔案且可直接運行的現代日系極簡風格 (可更改風格) HTML/CSS 網頁（index.html），

🌟【期中加分專區必加】：請在網頁中嵌入一個『產業商業數據視覺化儀表板 (Chart.js)』，展示近 5 年產業規模消長折線圖與營收結構甜甜圈圖，並附上 3 點商務洞察分析。
並幫我部屬到 GitHub，我不想自己上傳檔案所以給你這串 API key 你幫我上傳 (請貼上 GitHub Personal Access Token 亂碼)。
```

## 第四部分：GitHub Personal Access Token (API Key) 生成與自動發布指引

為了讓同學們享受現代 Vibe Coding「動口不動手」的流暢體驗，可以直接將 GitHub API Token 提供給 Antigravity，讓 AI 助理自動將生成的 `index.html` 推送至個人 GitHub 儲存庫：

### 4.1 生成 GitHub Personal Access Token (classic) 四步驟：
1. 點擊個人 GitHub 右上角頭像 ➔ 選擇「**Settings**」➔ 頁面捲動至最左下角點選「**Developer settings**」。
2. 點擊「**Personal access tokens**」➔ 選擇「**Tokens (classic)**」➔ 點選「**Generate new token (classic)**」。
3. 設定 Note 名稱為「`antigravity-deploy`」，Expiration 選擇「30 days」或「No expiration」，並在 Scopes 中務必勾選「**repo**」（包含完整儲存庫讀寫權限）與「**workflow**」。
4. 滑動至頁面最底端，點選綠色按鈕「**Generate token**」生成密鑰金鑰。
5. ⚠️ **【極重要安全提示】**：複製這串 Token 亂碼（以 `ghp_` 開頭），此金鑰僅會出現一次！請妥善保存，切勿隨意散佈給無關他人！

### 4.2 啟用 GitHub Pages 免費雲端靜態網頁發布：
1. 進入專案儲存庫頁面，點選上方功能導覽列的「**Settings**」（設定）。
2. 在左側選單中找到「Code and automation」區塊，點選「**Pages**」。
3. 在「Build and deployment」底下的「Branch」設定：將分支改選為 **main**，資料夾維持 **/(root)**，點擊右側「**Save**」。
4. 等待約 1~2 分鐘重新整理頁面，頂部將出現綠色提示：「`Your site is live at https://[您的帳號].github.io/[專案名稱]/`」。
5. 此網址即為期中報告必須提交之「線上公開部署網址」！
