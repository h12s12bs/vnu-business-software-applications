## 🌟 平台六大核心特色亮點

本平台專為萬能科技大學電腦教室授課環境量身研發，全面對標 **辦公軟體三件套 (Word / Excel / PPT)**、**Agentic AI 智慧代理人自主工作流** 與 **經濟部 iPAS「AI 應用規劃師」認證考科**：

1. **📌 第一週導論與全方位規範**：
   - **授課教師個人介紹**：邱俊維 博士（長庚大學管理研究所博士、萬能科大企管系助理教授）、專長領域（決策分析與作業研究、AI Agent 與軟體實務應用、全端開發、運籌管理）、實務與專案經歷（光明健康事業研發工程師兼特助、長庚大學國科會計畫研究助理、校務研究中心研究助理）、諮詢時間（每週一 15:00~16:00、週四 14:00~16:00）與聯絡方式。
   - **OBE 4 階段教學進度進行方式**：Hook 課堂破冰 (15分) ➔ Concept 觀念心法 (45分) ➔ Practice 實機演練 (90分) ➔ Wrap-up 反思評量 (30分)，搭配 ISO 8601 檔案命名規範與 CLEAR 提問原則。
   - **評分標準與規準 (Rubrics)**：平時出席 30%、期中書面報告 30%、期末綜合報告 40%（免上機測驗、無每週隨堂作業負擔），並提供 **iPAS「AI 應用規劃師」證照考取特別加分條款**（報名加 5 分、通過總成績直接加 10 分！）。

2. **📅 18 週進度地圖與教案卡片**：
   - 涵蓋 18 週完整模組（先導觀念、Word 商業文書、Excel 數據分析、PPT 提案簡報、綜合企業工作坊）。
   - 每週卡片提供：課堂痛點破冰 (Hook)、核心觀念 (Concept)、實機 SOP (Practice)、反思評量 (Wrap-up)、CLEAR 提示詞範本（支援一鍵複製）與 iPAS 考點對標。
   - 每週均配有 **「🖥️ 播放本週簡報 (61頁)」** 與 **「📝 隨堂快測 (5題)」** 專屬按鈕。

3. **🤖 Agentic AI 商業軟體應用實驗室 (Agentic AI Studio)**：
   - 提供 4 大商業實戰 Agent 範本：
     - 📄 **Word Document Agent**：智慧商業企劃書與合約自動化（黃金五結構、三線表、APA 引用）。
     - 📊 **Excel Data Analysis Agent**：智慧數據清洗與多維分析（TRIM/CLEAN、XLOOKUP/SUMIFS、切片器 Dashboard）。
     - 📑 **PPT Presentation Agent**：高說服力商業提案簡報（SCQA 金字塔、CRAP 圖解化、90 秒演講備忘稿）。
     - 🔄 **Multi-Agent Pipeline**：跨軟體企業營運全流程自動化代理集群（Supervisor 協調 Word + Excel + PPT 一條龍）。
   - 內建 **ReAct 推理引擎終端機**：逐步展示 Thought (思考) ➔ Action (工具調用 Tool Calling) ➔ Observation (觀察反思) ➔ Guardrails (安全審核) ➔ Human-in-the-Loop (人機審批) ➔ 交付成果。
   - 支援 **自訂商業任務模擬**：學生可輸入任意企業情境，觀察 Agentic AI 的自主調度過程。

4. **🎯 經濟部 iPAS「AI 應用規劃師」證照專區與自我評量**：
   - 預載 **210 題結構化自我評量題庫**（含科目一技術核心、科目二商業流程規劃與資安法規，每題皆有精闢詳解）。
   - 支援 4 種測驗模式：
     - **模式 A：每週 5 題隨堂快測**（各週核心觀念即時診斷）。
     - **模式 B：單元模組自主練習**（自選 Word、Excel、PPT 或 Agentic AI 弱點加強與觀念鞏固）。
     - **模式 C：期中 50 題自我檢測**（限時 60 分鐘，及格線 70 分，自我驗收）。
     - **模式 D：期末 100 題綜合自我評量**（限時 100 分鐘，全學期重點觀念總驗收）。
   - **純前端 SVG 專業能力落點雷達圖 (Competency Radar Chart)**：自動繪製 5 大專業維度強弱分佈，離線免外網即可運行！

5. **🏆 學習歷程勳章與個人錯題筆記本**：
   - 學生設定學號與姓名即可累積 8 大榮譽成就勳章。
   - **個人錯題筆記本 (Mistake Notebook)**：系統自動收錄答錯題目，支援「一鍵自主複習錯題」，觀念釐清與強化必備！

6. **🖥️ 18 週全功能全螢幕簡報播放系統**：
   - 頂部導覽列一鍵啟動全螢幕簡報模式，無縫調用現有 `slides_data.js` 的 1,098 頁高品質投影片！
   - 支援鍵盤快捷鍵：`Space` / `→` (下一頁)、`←` (上一頁)、`F` (全螢幕切換)、`N` (演講者備忘稿即時顯示)、`Esc` (退出返回互動平台)。

## 🚀 老師上課使用說明（三種運行模式）

### 模式一：GitHub Pages 雲端線上版 (學生免安裝隨開即用 🌐 最推薦)
- **公開線上網址**：[https://h12s12bs.github.io/vnu-business-software-applications/](https://h12s12bs.github.io/vnu-business-software-applications/)
- 學生使用手機、筆電或電腦教室電腦，直接點開網址即可即時使用 18 週教案、全螢幕簡報、Agentic AI 實戰沙盒、210 題自我評量與能力雷達圖！

### 模式二：電腦教室區域網路互動模式 (教師主機連線 👍)
1. 在教師主機上，直接雙擊點擊 **`啟動教學平台.bat`**。
2. 系統會自動啟動 Python 後端伺服器，並開啟預設瀏覽器進入 `http://localhost:5000`。
3. 平台右上角會顯示電腦教室的區域網路網址（例如：`http://120.124.20.34:5000`）。
4. **請老師將該網址投影至大螢幕**，全班學生於座位電腦打開 Chrome 或 Edge 瀏覽器輸入該網址即可同步連線操作、進行隨堂測驗與沙盒模擬！

### 模式三：單機離線免安裝模式 (零網路環境備援 👍)
- 若教室網路不穩或電腦未安裝 Python，可直接將 **`平台首頁(單機離線直接點開).html`** 或 **`index.html`** 發送給學生（或放至隨身碟/Google 雲端硬碟）。
- 雙擊該 HTML 檔案即可在任何瀏覽器中離線運行所有模擬器、18 週地圖、雷達圖與 210 題題庫測驗！
